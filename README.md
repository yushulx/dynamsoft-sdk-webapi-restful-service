# Dynamsoft Vision SDK RESTful Service

This repository provides the source code for a RESTful service utilizing Dynamsoft Vision SDKs, enabling powerful document, 1D/2D barcode, and MRZ processing features through a web API.

## Features
- **Document Scanning**: Capture documents from Multi-Function Printers (MFPs) and document scanners.
- **Barcode Detection**: Accurately detect and decode various barcode formats.
- **Machine Readable Zone (MRZ) Recognition**: Extract information from MRZs on passports and other identification documents.
- **Document Edge Detection and Perspective Correction**: Automatically detect document edges and correct perspectives for better visual presentation.

## Supported Programming Languages
- [C#](dotnet/)
- [Python](python/)
- [Node.js](node/)
